# CLAUDE.md (flow)

Own skill, living in `~/Projects/skills/skills/flow` (the shared repo, see its root CLAUDE.md); `~/.claude/skills/flow` links here. Edit and commit here.

- Works alone in any repo, and inside a `task` folder (`skills/task`) through `--specs`. `task`'s `status.py` reads `feature.yaml` (`status`, `repo`, `story`): change both together when the feature format moves.
- Each feature is `spec.md` (prose, from `templates/spec.md`) plus `feature.yaml` (everything the script checks). Status changes, `new` (the feature skeleton), `finding` and `roadmap --approve` go through `scripts/flow.py`. The generic helpers (YAML reading and line edits, git, cycles, today, next id) come from the repo's `lib/`; `task`'s scripts load only `scripts/roadmap.py`, by its file path, and call its `sync_roadmap`, `statuses`, `links_of`, `linked_statuses`, `roadmap_features` and `features_from` (the one reader of the roadmap features and the feature files, over data the caller loads): keep those names, and keep `roadmap.py` importing only `lib/` and the standard library, since flow's folder is not on task's import path.
- The review lives in `review.yaml` beside `feature.yaml`, owned by `flow.py finding`. `skills/code-review` (step 6) calls `finding` with its flags (`--text --source --severity --confidence --file --line --hunk --fix`, `--none --axes`): change both together when those flags move.
- `scripts/flow.py` is the command line only (arguments, dispatch, the roadmap sync after a command); each context has its module, importing the others by plain name: `feature.py` (finding a feature, its checks, the frontier), `review.py` (`review.yaml` and `finding`), `roadmap.py` (the roadmap and its status rule), `progress.py` (`set`), `commands.py` (status, check, approve, review, finish, pr, new). Keep each about 300 lines at most: a new context gets a new module.
- `scripts/flow.py` needs PyYAML. Its tests drive the CLI only; the repo root pre-commit hook runs them when this skill is staged (command: its `test:` in the root `skills.yaml`).
- Commits: Conventional Commits in English, subject states the why, stage files by name.
