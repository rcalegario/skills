# <slug> brief

## BRIEF-1 Today

How it works now, in a few paragraphs, citing context ids. One picture of today (call tree, file tree, Mermaid) when the shape is the point.

## BRIEF-2 Target

What becomes true when the task is done, per item (AC-n, X-n), and where it departs from the base text. A `diff` over today's shape when the change is structural.

## BRIEF-3 Path

How we get there: the decided approach, the order of the work, the validations that close each item. A Mermaid `flowchart` when the order is not linear.

## BRIEF-4 Open items

- Decisions still open or proposed, with who decides.
- Pending items with other people or tasks.
